**ClickMeter 1.0.1** for Windows 10/11 (x64) · Free for personal use

### What's new

- Right-click and middle-click tracking — enable L / R / M chips per session
- Configurable CPS history window — full session, 30s, 60s, 2 min, 5 min, or a custom duration
- Sidebar navigation replaces the old settings popup — settings is now an inline screen
- Strict click hit-testing — clicks only count inside the click target
- Theme preset chips restyled to outlines for readable contrast on every theme
- CPS history now kept unbounded until Reset Session (display window is independent)
- About and Settings reorganised into card-based sections
